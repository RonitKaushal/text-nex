# TextNexus Releases

Official **installer downloads** for [TextNexus](https://github.com) desktop app.

This repository is used only for **GitHub Releases** (`.exe` installers).  
Source code lives in a separate private project.

## Download

Go to **[Releases](../../releases)** → open the latest version → download:

`TextNexus-x.y.z-win-x64.exe`

## For users

1. Download the latest `.exe` from Releases  
2. Run the installer and follow the steps  
3. After install, open **Profile** in TextNexus  
4. If a newer update is published, the **Update** button turns **green** — click it to download automatically  

## Version history

All versions and changelogs are listed on the [Releases](../../releases) page.

## Support

If install or update fails, contact your TextNexus admin / support.
